# SkillSync AI - Jobs Service

Microservicio encargado de administrar ofertas laborales y empleos guardados.

## Responsabilidades

- Listar ofertas tecnológicas
- Ver detalle de oferta
- Recomendar ofertas según perfil
- Guardar ofertas
- Eliminar ofertas guardadas

## Ejecutar

```bash
uvicorn app.main:app --reload --port 8004
